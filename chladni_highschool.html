중등/흥미고등/수능🎯 도입 — 소리를 눈으로 볼 수 있을까?
🎯 이 단원에서 배우는 것 — 금속판에 모래를 뿌리고 스피커로 떨게 하면, 어떤 진동수에서 모래가 갑자기 움직여 아름다운 줄무늬를 만듭니다. 이것이 클라드니 무늬(Chladni figure)입니다. 줄무늬는 판이 떨지 않는 곳(마디선)의 지도라서, 무늬를 읽으면 판의 진동 모드 · 공명 진동수 · 재질의 탄성을 알 수 있고, 같은 원리로 악기를 만들고 · 결함을 찾고 · 세포를 줄 세웁니다.
🧭 선행조직자(Advance Organizer) — 오수벨
「역학과 에너지」에서 양 끝을 고정한 줄에 파동을 보내면 반사파와 겹쳐 정상파가 생기고, 늘 멈춰 있는 마디와 가장 크게 떠는 배가 번갈아 나타난다는 것(p.108~112), 그리고 외부에서 흔드는 진동수가 고유 진동수와 같으면 진폭이 커지는 공명을 배웠습니다. 줄의 단진동 변위는 $y=A\sin\omega t$ 였습니다(p.88~91). 이제 줄을 판으로 넓혀 봅시다. 판에서는 마디가 점이 아니라 선이 되고, 공명이 일어나는 진동수마다 마디선의 모양이 달라집니다. 모래는 그 마디선으로 모여 보이지 않던 정상파를 그림으로 바꿔 줍니다.
줄의 정상파 (마디 · 배)→ 판의 정상파 = 마디선→ 공명 진동수마다 다른 모드→ 무늬를 읽어 세상을 잰다

🧰 이 단원의 도구 6가지와 역할
① 정상파판 끝에서 반사된 굽힘파가 겹쳐 제자리에서 떠는 파동이 된다. 줄의 정상파(p.108~112)를 두 방향으로 넓힌 것(2번 탭).
② 마디선 · 배변위가 늘 0 인 선이 마디선, 가장 크게 떠는 곳이 배. 모래가 그리는 줄 = 마디선(1 · 4번 탭).
③ 공명 · 모드판은 정해진 진동수에서만 크게 떤다. 진동수마다 다른 무늬가 하나의 「모드」 이며 (m, n) 으로 이름을 붙인다(3번 탭).

⑤ 문턱 가속도 g판의 가속도 $(2\pi f)^2A$ 가 g 보다 클 때만 모래가 뜬다. 이 문턱으로 판 위에서 g 를 잰다(4 · 16번 탭).
⑥ 비접촉 · 위상 측정레이저 반사 · 두 점 리사주로 모래 없이 마디선을 찾는다 — 07 리사주 · 13 비접촉 단원과 잇는다(6번 탭).

🥁 쉽게 이해하기 — 트램펄린 위의 공
여러 사람이 트램펄린 가장자리를 박자 맞춰 누르면, 어떤 곳은 크게 출렁이고 어떤 곳은 거의 가만히 있습니다. 그 위에 작은 공을 잔뜩 올려 두면 출렁이는 곳의 공은 튕겨 나가고, 가만히 있는 곳에 떨어진 공만 그 자리에 남습니다. 시간이 지나면 공들이 「가만히 있는 곳」 을 따라 줄을 섭니다 — 클라드니 무늬입니다.

📐 식으로 정리하기 고등

판 위 한 점의 변위 $z(x,y,t)=A\,\phi_{mn}(x,y)\cos\omega t$ — 마디선은 $\phi_{mn}=0$ 인 곳. 가장 센 곳의 가속도 $a=\omega^2A=(2\pi f)^2A$.

모래가 뜨는 조건 : $(2\pi f)^2A\,|\phi|>g$ → 마디선 가까이($|\phi|$ 작음)에서는 늘 문턱 아래 → 모래가 머문다.

교과서 밖 : 얇은 판의 굽힘 방정식 $D\nabla^4 z+\rho h\,\ddot z=0$, $D=\dfrac{Eh^3}{12(1-\nu^2)}$ → $\omega=\sqrt{D/\rho h}\;k^2$. 이 화면은 가장자리 기울기가 0 인 코사인 모드 $\phi=\cos\frac{n\pi X}{L}\cos\frac{m\pi Y}{L}\pm\cos\frac{m\pi X}{L}\cos\frac{n\pi Y}{L}$ 로 자유판을 어림합니다(리츠 1909 의 정확한 해와 모양은 비슷하나 진동수 비는 다름).

고등/수능POE3D🌊 원리① 줄에서 판으로 — 정상파의 마디
🎯 이 탭에서 배우는 것 — 반대로 가는 두 파동이 겹쳐 생기는 정상파에서 마디(늘 멈춤)와 배(가장 크게 떪)가 왜 생기는지, 마디 사이 간격이 왜 반 파장(λ/2)인지 확인합니다. 그리고 줄을 막(2차원)으로 넓혀, 마디가 점에서 선으로 바뀌고 가로 · 세로 두 방향의 정수 (m, n) 이 모드를 정한다는 것을 봅니다.
🧭 선행조직자 — 교과서 p.108~112 정상파 · 공명
양 끝이 고정된 줄에서 오른쪽으로 가는 파동 $y_1=\tfrac{A}{2}\sin(kx-\omega t)$ 와 반사되어 돌아오는 파동 $y_2=\tfrac{A}{2}\sin(kx+\omega t)$ 가 겹치면 $y=A\sin kx\cos\omega t$ — 모양은 제자리에 있고 크기만 커졌다 작아졌다 하는 정상파가 됩니다. $\sin kx=0$ 인 곳이 마디이고, 이웃한 마디 사이는 $\lambda/2$ 입니다. 줄 길이 L 안에 반 파장이 n 개 들어가야 하므로 $L=n\lambda/2$, 고유 진동수 $f_n=\dfrac{nv}{2L}$ 입니다.
진행파 두 개가 겹침→줄의 마디 = 점→막의 마디 = 선 (m, n)→판 : 굽힘파 f ∝ 1/d²
🔬 원리 살펴보기 — 줄의 마디와 막의 마디선 중등부터
그림 2-1. 줄(1차원)의 정상파와 막(2차원)의 정상파 — 줄에서는 마디가 점, 막에서는 마디가 선이 된다. 막의 (3, 2) 모드는 가로로 반 파장 3개 · 세로로 2개가 들어가 +/− 칸이 바둑판처럼 번갈아 떨고, 칸의 경계가 마디선이다
🧰 구성 요소와 역할
① 고정 끝줄 끝 · 막의 테두리는 움직이지 못하므로 늘 마디다. 파동이 여기서 반사되어 되돌아와 정상파를 만든다.
② 마디 (점)두 진행파가 늘 반대 위상으로 만나 변위가 0. 하지만 장력은 계속 작용한다 — 에너지는 마디 양쪽을 오간다.
③ 배두 파동이 같은 위상으로 만나 진폭 A 로 떤다. 이웃한 배끼리는 반대 방향으로 움직인다(위상차 180°).
④ 마디 간격 λ/2$\sin kx=0$ 인 점 사이 거리 = $\pi/k=\lambda/2$. 마디 간격을 재면 파장을 안다 — 클라드니 무늬 간격도 같은 뜻(14번 탭).
⑤ 막의 마디선$z=A\sin\frac{m\pi x}{L}\sin\frac{n\pi y}{L}\cos\omega t$. 가로 m 개 · 세로 n 개의 반 파장 → 안쪽 마디선 (m−1) + (n−1) 개.
⑥ 소금이 모이는 선+ 칸과 − 칸의 경계에서 막이 떨지 않으므로 소금 · 모래가 격자 모양으로 모인다(교실 실험).
🧪 교실 실험 — 풍선막 위의 소금 (막의 정상파)
장치 : 스피커를 위로 향하게 놓고 그 위에 입구가 넓은 플라스틱 통(또는 종이컵 여러 개를 자른 원통)을 세운다. 풍선을 잘라 통 입구에 팽팽하게 씌우고 고무줄로 묶는다.
소리 내기 : 스마트폰 톤 생성 앱 → 스피커. 볼륨을 중간에 두고 50 Hz 부터 천천히 올린다.
관찰 : 소금이 갑자기 움직여 무늬를 만드는 진동수(공명)를 적고, 그때의 무늬(마디 원 · 마디 지름)를 사진으로 남긴다.
비교 : 막을 더 팽팽하게(장력 ↑) 하면 같은 무늬의 진동수가 어떻게 바뀌는가? 막 : $f\propto\sqrt{T}$ (5번 탭 · R02).
기록 : 진동수 – 무늬 표를 만들고, 다음 탭의 금속판(굽힘파)과 무엇이 다른지 적는다 → 보고서 실험 B 준비.

📐 식으로 정리하기 고등

예 : f = 200 Hz, 배의 진폭 A = 0.05 mm → $(2\pi\cdot200)^2\times5\times10^{-5}\approx79\;\text{m/s}^2\approx8\,g$.

교과서 밖 : 알갱이가 판을 떠나는 위상 $\sin\omega t_0=g/(\omega^2A)$ 와 비행 뒤 다시 만나는 조건은 「튀는 공」 문제(주기 배가 · 혼돈)로 이어집니다. 가루가 배로 가는 것은 떠는 판 위 경계층의 정상 흐름(레일리 음향 흐름)이 마디 → 배 방향으로 생기기 때문이며, 진공에서는 가루도 마디로 갑니다. 알갱이 위치의 시간 변화는 위치에 따라 확산 계수가 다른 확산(D(x) ∝ 초과량²)으로 볼 수 있습니다.

고등/심화POE3D🥁 원형 판 · 막 · 악기 — 클라드니 법칙
🎯 이 탭에서 배우는 것 — 둥근 판의 마디선은 지름(마디 지름 m 개)과 원(마디 원 n 개) 두 종류입니다. 클라드니는 둥근 판의 진동수가 대략 $f\approx C\,(m+2n)^2$ 을 따른다는 것을 찾았습니다(클라드니 법칙). 금속 판과 북(막)의 차이, 그리고 바이올린 · 기타 · 종 · 심벌즈 같은 악기가 이 모드들로 소리를 만든다는 것을 봅니다.
🧭 선행조직자 — 2 · 3번 탭의 모드 번호
정사각형 판에서는 가로 · 세로 마디선 수로 모드를 불렀습니다. 둥근 판에서는 방향이 둘레(각도 θ)와 반지름(r)이므로, 변위를 $z=R(r)\cos m\theta\cos\omega t$ 로 나눠 생각합니다. $\cos m\theta=0$ 인 곳이 마디 지름 m 개, $R(r)=0$ 인 곳이 마디 원 n 개입니다. 반지름 방향 모양 R(r) 은 베셀 함수라는 특별한 함수가 되지만(교과서 밖), 무늬를 세는 방법은 지금까지와 같습니다.
정사각 판의 (m, n)→둥근 판 : 지름 m · 원 n→f ≈ C(m + 2n)²→악기 판 · 북 · 종
🔬 원리 살펴보기 — 둥근 판의 무늬 여섯 가지 중등부터
그림 5-1. 가장자리가 자유로운 둥근 판의 무늬 — 키르히호프 판 이론으로 계산한 마디선(노랑)과 진동수 비. 클라드니 법칙 $f\approx C(m+2n)^2$ 은 m + 2n 이 커질수록 잘 맞고, 마디 원이 있는 모드(n ≥ 1)는 C 가 약 1.8 배 큰 따로 줄에 선다(R05 에서 직접 확인)
🧰 구성 요소와 역할
① 마디 지름$\cos m\theta=0$ 인 선. 둘레를 따라 +/− 가 2m 번 바뀐다. 가장 낮은 모드는 (2, 0) 십자(가장자리가 자유라 m = 0 · 1 의 n = 0 은 없음).
② 마디 원반지름 방향 모양 R(r) 이 0 인 원. 가운데와 바깥이 반대로 떤다 — 종 · 심벌즈의 「웅」 소리.
③ 지름 + 원둘이 함께 있는 모드는 바둑판처럼 칸이 나뉜다. 칸마다 이웃과 반대로 떤다.
④ 진동수 비판은 $f=\dfrac{\lambda^2}{2\pi a^2}\sqrt{\dfrac{D}{\rho h}}$ — λ² 가 모드마다 다른 수(5.26 · 9.07 · 12.2 · 20.5 …). 정수배가 아니라 판의 소리는 음정이 뚜렷하지 않다.
⑤ 클라드니 법칙$f\approx C(m+2n)^p$, p ≈ 2 — 마디 원 하나를 지름 두 개로 쳐서 세는 어림 규칙. 계산해 보면 n = 0 과 n ≥ 1 이 C 가 약 1.8 배 다른 두 줄로 나뉜다.
⑥ 크기 · 막과 판판은 $f\propto h/a^2$ (굽힘), 막(북)은 장력으로 $f\propto\sqrt{T}/a$. 북의 배음 비는 1 : 1.59 : 2.14 : 2.30 … 로 역시 정수배가 아니다.

둥근 판 : 지름 24 cm 알루미늄 원판(주방용 쟁반 · 냄비 뚜껑도 가능) 가운데를 가진기에 고정하고 소금을 뿌려 진동수를 훑는다.

법칙 확인 : log f – log(m + 2n) 그래프를 그려 기울기 p 를 구한다(n = 0 과 n ≥ 1 을 다른 색으로) → R05.

🎯 이 탭에서 배우는 것 — 모래는 편하지만 판을 더럽히고, 판이 기울거나 세로로 서 있으면 쓸 수 없습니다. 두 가지 「업그레이드」 를 봅니다. ① 두 점 리사주 : 두 점의 진동을 오실로스코프 XY 로 겹치면, 같은 칸끼리는 + 기울기 직선, 마디선을 건넌 점과는 − 기울기 직선이 됩니다(07 리사주 단원). ② 레이저 도플러 스캔 : 레이저 빛의 진동수 변화(도플러 효과)로 판에 닿지 않고 점마다 진동 속도를 재어 모드 지도를 그립니다(13 비접촉 측정 단원).
🧭 선행조직자 — 07 리사주 도형 · 13 비접촉 측정 · 교과서 p.104~105 위상
정상파에서 이웃한 칸(+ 칸과 − 칸)은 늘 반대 방향으로 움직입니다 — 위상차 180°. 07 단원에서 배운 것처럼 진동수가 같은 두 신호를 XY 로 겹치면 위상차 0° 는 / 모양 직선, 180° 는 \ 모양 직선, 그 사이는 타원입니다. 그러니 한 점 A 를 기준으로 두고 다른 점 B 를 옮기며 직선의 기울기가 뒤집히는 곳을 찾으면 그곳이 마디선입니다. 한편 13 단원에서는 빛(광자)으로 과일 속을 닿지 않고 쟀습니다. 움직이는 면에서 반사된 레이저는 속도에 비례해 진동수가 바뀌므로(도플러 효과), 이것으로 판의 떨림을 닿지 않고 잽니다.

② 레이저 진동계면이 속도 v 로 움직이면 반사광의 진동수가 $\Delta f=2v/\lambda$ 만큼 바뀐다. 기준광과 섞어 이 차이(맥놀이)를 세면 닿지 않고 속도를 안다.

교과서 밖 : 실제 판은 감쇠 때문에 위상차가 정확히 0° · 180° 가 아니고 가는 타원이 됩니다. 두 모드가 가까운 진동수에서 함께 들뜨면 마디선이 「움직이는」 것처럼 보이기도 합니다(복소 모드). 스캐닝 레이저 진동계는 헤테로다인 간섭(브래그 셀로 기준광을 40 MHz 옮김)으로 속도의 부호까지 잽니다.

import numpy as np, matplotlib.pyplot as plt
# 1) 자유판 교육용 모형 무늬 : cos(n pi x) cos(m pi y) ± cos(m pi x) cos(n pi y) = 0 (x, y : 0~1)
m, n, s = 1, 3, -1
x, y = np.meshgrid(np.linspace(0, 1, 400), np.linspace(0, 1, 400))
z = np.cos(n*np.pi*x)*np.cos(m*np.pi*y) + s*np.cos(m*np.pi*x)*np.cos(n*np.pi*y)
plt.subplot(1, 3, 1); plt.contour(x, y, z, [0], colors='k'); plt.gca().set_aspect(1); plt.title(f'({m},{n}){"-" if s<0 else "+"}')

# 2) 모드 사다리 f = F1 (m^2 + n^2)  — F1 = (pi/2L^2) h sqrt(E / (12 rho (1-nu^2)))
E, rho, nu, h, L = 69e9, 2700, 0.33, 1e-3, 0.24
F1 = np.pi/(2*L*L)*h*np.sqrt(E/(12*rho*(1-nu*nu)))
modes = sorted([(F1*(a*a+b*b), a, b) for b in range(1, 8) for a in range(0, b+1) if a+b >= 2])
plt.subplot(1, 3, 2); plt.plot([a*a+b*b for f, a, b in modes], [f for f, a, b in modes], 'o'); plt.xlabel('m²+n²'); plt.ylabel('f (Hz)')

# 3) [종합1] 원점 회귀로 E 구하기 — 측정한 (m, n, f) 를 넣으세요 (L = 0.30 m 단순 지지 판)
data = [(1,1,54.1), (1,2,134.6), (2,2,216.3), (1,3,269.4), (2,3,351.2)]
X = np.array([(a*a+b*b)/0.30**2 for a, b, f in data]); F = np.array([f for a, b, f in data])
sl = (X@F)/(X@X); Ee = 12*rho*(1-nu*nu)*(2*sl/(np.pi*h))**2
plt.subplot(1, 3, 3); plt.plot(X, F, 'o', X, sl*X, '-'); plt.title(f'E = {Ee/1e9:.1f} GPa')
plt.tight_layout(); plt.show()

가설 : 모래가 뜨는 문턱에서 $A=\dfrac{g}{(2\pi f)^2}$. 양변에 로그를 취하면 $\log A=-2\log f+\log\dfrac{g}{4\pi^2}$ — 로그–로그 그래프는 기울기 −2 인 직선이다.

분석 : 가로축을 측정 범위 한가운데로 중심화한 $X=\log_{10}(f/f_c)$, $f_c=190$ Hz 로 두고 $\log_{10}A$ 를 회귀 → 기울기(−2 인가?) · 절편에서 $A_c$ → $g=A_c(2\pi f_c)^2$. (중심화하지 않으면 절편이 f = 1 Hz 까지 멀리 외삽되어 오차가 커진다 — 누적 사전 §2-E)
볼륨 천천히 ↑→ 모래가 뜨는 순간 →문턱 진폭 A→ 중심화 로그–로그 →기울기 −2 · 절편→g = A꜀ (2πf꜀)²
🔬 실험 장치 — 가진기 위 모래 쟁반과 진폭 측정 중등부터
그림 16-1. 문턱 진폭 측정 — 진동수마다 볼륨을 천천히 올리다 모래 절반 이상이 뛰는 순간의 진폭 A 를 잰다. 600 Hz 의 문턱은 약 0.7 μm 로 매우 작아 레이저 진동계(6번 탭 · 13 비접촉 단원)가 필요하다
🧰 실험 기구와 역할
① 신호 발생기 · 앰프진동수를 고정하고 볼륨만 천천히 올린다. 문턱 근처에서는 한 칸씩.
② 모래 쟁반가진기에 단단히 붙인 가볍고 뻣뻣한 쟁반 — 판처럼 휘지 않고 통째로 움직여야 모든 모래가 같은 조건.
③ 레이저 진동계쟁반 옆면에 비춰 진폭을 닿지 않고 잰다. 높은 진동수의 아주 작은 진폭(μm 이하)을 잴 수 있다.
④ 가진기진동수가 바뀌어도 쟁반이 피스톤처럼 움직이는 범위(쟁반 자체의 공명보다 낮은 진동수)에서 쓴다.
⑤ 가속도계낮은 진동수에서 레이저 값을 교차 확인(a = (2πf)²A). R04 스마트폰 방법과 같다.
⑥ 로그–로그 그래프중심화한 가로축 X = log(f/190 Hz). 기울기 −2 확인 · 절편 → g.

🛗 쉽게 이해하기 — 급하게 내려가는 엘리베이터
엘리베이터가 아주 빨리 내려가기 시작하면 몸이 붕 뜨는 느낌이 듭니다. 바닥이 떨어지는 가속도가 g 에 가까울수록 바닥을 누르는 힘이 줄고, g 를 넘으면 몸이 바닥에서 떨어집니다. 모래도 똑같이 — 쟁반이 아래로 g 보다 빨리 가속하는 순간 떠오릅니다. 그러니 「뜨는 순간」 은 g 를 재는 자입니다.

📐 식으로 정리하기 고등
