고등/수능실험POE📊 [종합3] 잡음과 평균 — SNR 의 √N 법칙
🎯 이 실험에서 하는 것 — 같은 대상을 N 장 찍어 평균하면 신호 대 잡음비(SNR)가 얼마나 좋아지는지 측정합니다. $\mathrm{SNR}$ 대 $\sqrt N$ 그래프는 원점을 지나는 직선이고 기울기가 한 장의 SNR 입니다. 결과는 보고서의 실험 D가 됩니다. (CT · MRI · 초음파의 평균 · 선량 · 촬영 시간 거래의 핵심)
🧭 선행조직자 — 평균은 잡음을 √N 만큼 줄인다
신호는 쌓이면 N 배, 서로 독립인 잡음은 √N 배로만 커지므로 평균하면 SNR 은 √N 배 좋아집니다. 화질을 2 배 좋게 하려면 촬영 시간(또는 선량)이 4 배 필요합니다 — 의료영상에서 선량과 화질의 거래.
신호 N 배→잡음 √N 배→SNR ∝ √N→선량 4 배 = 화질 2 배

모형 : 측정 SNR = SNR₁ √N (1 + 0.07 ε), ε 는 가우시안 잡음(측정 SNR 자체의 흔들림). 한 장의 숨은 SNR₁ 은 [새 조건]마다 2 ~ 5 에서 뽑힙니다.

기록한 값은 실험보고서(19번 탭)의 표 · 그래프 · 결과로 자동으로 이어집니다. 5개 이상 모으세요.

왼쪽 : 한 장(잡음 많음), 오른쪽 : N 장 평균(깨끗). 같은 팬텀 · 같은 신호입니다(10 초 반복).
📊 가로 $\sqrt N$ · 세로 SNR. 빨강 = 내 회귀직선, 흰 점선 = 숨은 참 직선. 기울기 = 한 장의 SNR.
📐 식으로 정리하기 고등

$\mathrm{SNR}_N=\sqrt N\,\mathrm{SNR}_1$ → 기울기 $s=\mathrm{SNR}_1$. 필요한 평균 장 수 $N=(\mathrm{SNR}_목표/\mathrm{SNR}_1)^2$. 예 : $s=3.0$ 에서 목표 12 → $N=16$.

교과서 밖 : X선 · CT 는 광자 수 $N_\gamma$ 의 포아송 잡음이라 $\mathrm{SNR}\propto\sqrt{N_\gamma}\propto\sqrt{\text{선량}}$. MRI 는 신호 평균 횟수(NEX) $\sqrt{\mathrm{NEX}}$. 상관된 잡음에서는 평균 효과가 줄어듭니다.

준비 : 스마트폰으로 어두운 장면(저조도)을 같은 위치에서 고정해 연속 촬영(삼각대).
측정 : 한 장의 관심영역(ROI) 평균 밝기 대비 표준편차로 SNR₁ 을 구한다(R09 참고).
평균 : N = 1, 4, 9, 16 장을 평균한 영상의 SNR 을 계산한다(파이썬 numpy).
그래프 : SNR 대 √N 점을 찍고 기울기가 SNR₁ 과 일치하는지 본다.
결론 : 선량 · 시간 · 화질 거래와 한계(움직임, 비독립 잡음)를 서술한다.
