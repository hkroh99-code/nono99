고등/수능실험POE📊 [종합1] 감약계수 μ 재기 — 램버트–비어 법칙
🎯 이 실험에서 하는 것 — 흡수체(물 · 필름 더미) 두께 $x$ 를 바꾸어 통과한 빛(X선 모사)의 세기 $I$ 를 재고, $\ln(I_0/I)$ 대 $x$ 의 그래프를 그려 원점을 지나는 직선의 기울기 = 감약계수 $\mu$ 를 구합니다. 반가층 $\mathrm{HVL}=\ln2/\mu$ 도 구합니다. 여기서 모은 값은 실험보고서의 실험 A가 됩니다. (실제 방사선이 아닌 안전한 가상 · 빛 실험입니다)
🧭 선행조직자 — 지수를 로그로 펴기
$I=I_0e^{-\mu x}$ 는 곡선이지만 양변에 로그를 취하면 $\ln(I_0/I)=\mu x$ — 직선입니다. 직선의 기울기 하나로 물질의 감약계수가 정해지고, 검출한 광자 수가 적을수록 포아송 잡음이 커서 점이 흩어집니다.
$I=I_0e^{-\mu x}$→$\ln(I_0/I)=\mu x$→기울기 = $\mu$→HVL = $\ln2/\mu$

📋 측정 기록표 0개

기록한 값은 실험보고서(19번 탭)의 표 · 그래프 · 결과로 자동으로 이어집니다. 5개 이상 모으세요.

광원(왼쪽) → 흡수체(가운데) → 검출기(오른쪽). 점 = 광자, 흡수체에서 흡수되면 사라집니다(10 초 반복).
📊 가로 두께 $x$ · 세로 $\ln(I_0/I)$ 산점도. 빨강 = 내 회귀직선, 흰 점선 = 숨은 참 직선. 기울기가 $\mu$.
📐 식으로 정리하기 고등

$\ln(I_0/I)=\mu x$ → 기울기 $s=\mu$. $\mathrm{HVL}=\ln2/\mu$. 예 : $s=0.20$ → $\mathrm{HVL}=3.5$ cm. 포아송 잡음 : $\dfrac{\delta\ln(I_0/I)}{1}\approx\dfrac{1}{\sqrt I}$ 이므로 광자 수가 4 배면 불확실성 ½.

교과서 밖 : 실제 X선은 다색 스펙트럼이라 두께가 늘수록 평균 에너지가 올라가(선질경화) 로그 그래프가 약간 휘고, 조직 · 에너지마다 μ 가 다릅니다(2번 탭의 μ(E)). CT 의 HU 는 $\mu$ 를 물 기준으로 바꾼 값입니다.

준비 : 안전한 대용 실험 — LED 광원 + 조도계(스마트폰 조도 앱) + 투명 OHP 필름 여러 장(또는 색 용액 층).
측정 : 필름 장수 N 을 0, 1, 2 … 10 으로 바꾸며 조도 E 를 3 회씩 재어 평균한다(R01 참고).
그래프 : $\ln(E_0/E)$ 대 N 의 점을 찍고 직선 기울기를 구한다(스프레드시트 · 파이썬, 14번 탭 코드).
해석 : 기울기 = 필름 한 장의 감약 지수 → 반가층(장 수) 구하기.
결론 : 조명 불균일 · 반사 · 센서 포화 같은 오차 원인과 실제 X선과의 차이를 서술한다.
