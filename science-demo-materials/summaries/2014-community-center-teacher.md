# 지역아동센터 보급용 과학 수업 원고 (교사용, 2014)

- **자료명**: 2011-2014 지역아동센터 보급용 원고(교사용). 본문 첫머리 표기는 "2014 지역아동센터보급용원고(교사용).hwp"
- **지원**: 각 차시 끝에 "2014년도 정부(과학기술진흥기금/복권기금)의 재원으로 한국과학창의재단의 지원을 받아 수행된 성과물"이라고 적혀 있음. 집필 교사 이름과 단체명은 텍스트에 없음(수업 스케치에 "**고등학교 화학 선생님", 육아휴직 중인 교사 등으로만 나옴).
- **대상·성격**: 지역아동센터 초등 저학년~중학생을 위한 체험형 과학 수업 지도안. 교사가 봉사 수업을 하며 쓴 기록이 함께 실려 있음.
- **차시 구성**: 관련 교육과정 → 소요 시간·적용 학년 → 학습목표 → 수업 흐름도(동기유발·주요활동·정리) → 나의 수업 스케치(교사 수업 후기) → 교육과정 연계(비전공자용 안내) → 준비물(구입처·키트 가격) → 수업 전 준비사항 → 본 활동(지도 팁) → 완성품·활동 장면 → 핵심용어 → 읽기자료 → 활동지(정답 예시)

## 고교 물리 수업에 바로 쓸 만한 실험

이 자료는 초·중학생용이라 6개 차시 모두 물리 내용이 들어 있습니다. 고교 수업에서 깊이를 더할 수 있는 지점을 중심으로 정리했습니다.

1. **성냥개비로 신문지 뚫기 (6차시)**
   - 관련 단원: 일과 운동 에너지(일-에너지 정리), 충격량과 운동량
   - 수업 활용: 빨대 길이(힘을 받는 거리)를 변인으로 사거리나 관통 여부를 비교하고, W = F·s = ½mv²로 정량 해석. 원문의 "거리를 늘려 가며 겨루는 대회" 방식을 그대로 써서 모둠 탐구로 운영할 수 있음.

2. **전자기타 만들기 (4차시)**
   - 관련 단원: 현의 정상파와 고유 진동수, 소리의 3요소
   - 수업 활용: 기타 튜너 앱(원문은 gStrings 추천)으로 줄 길이별 진동수를 재서 길이–진동수 반비례 관계를 그래프로 확인. 원문 정답 예시(가장 긴 줄 185.2Hz, 가장 짧은 줄 2637Hz)를 비교 기준으로 쓸 수 있음. 원문 수업 스케치가 전자기 유도는 고등학생 때 배울 내용이라고 짚고 있어, 고교에서는 픽업 원리까지 연결하기 좋음.

3. **종이컵 스피커 만들기 (3차시)**
   - 관련 단원: 자기장 속 전류가 받는 힘, 스피커·검류계·전동기
   - 수업 활용: 코일 감은 수나 자석 개수를 바꿔 소리 크기를 비교(원문: 자석을 하나 더 붙이니 소리가 커짐). 읽기자료의 검류계 원리(자기력 돌림힘과 스프링 복원력의 평형)는 전류계·전압계 설명에 바로 쓸 수 있음.

4. **전해질 탐지 광섬유 연등 (2차시)**
   - 관련 단원: 전반사와 광섬유(광통신), 전기 전도(자유 전자와 이온)
   - 수업 활용: 광섬유를 이리저리 휘어도 끝에서만 빛이 나오는 관찰을 임계각 조건과 연결. 금속(자유 전자)과 전해질(이온) 전도를 비교하는 도입 활동으로도 활용 가능. 원문 심화 내용에 할핀 전극에서 전기분해가 일어난다는 언급이 있음.

5. **알록달록 빛 상자 (5차시)**
   - 관련 단원: 빛의 반사 법칙, 빛의 합성(가산 혼합)과 색 필터
   - 수업 활용: 원문 지도 팁대로 빛의 삼원색(빨강·초록·파랑)과 색의 삼원색(자홍·노랑·청록)만으로 칠해 비교하면 가산·감산 혼합을 한 번에 다룰 수 있음. 원문의 페르마 원리 언급을 반사 법칙 유도의 출발점으로 쓸 수 있음.

6. **반짝이는 목걸이 (1차시)**
   - 관련 단원: 직류 회로, 다이오드(LED)의 극성과 문턱 전압
   - 수업 활용: 원문 지도 팁(LED는 대체로 2.2~3.5V에서 작동, 긴 다리 +)을 바탕으로 수은전지 1개와 2개(직렬)일 때 LED가 켜지는지 비교하게 하면 직렬 연결과 다이오드 특성을 함께 다룰 수 있음.
