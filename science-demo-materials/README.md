# 일본 과학제전·물리 데모 실험 자료

도쿄 지역의 '청소년을 위한 과학제전(青少年のための科学の祭典)'과 물리 데모 실험 관련 공개 자료 모음입니다.

## 내려받기

```bash
bash tokyo-physics-materials/scripts/download.sh
```

`sources.tsv`에 적힌 파일을 `pdf/<분류>/` 아래로 내려받습니다. 이미 받은 파일은 건너뜁니다.
새 자료를 추가하려면 `sources.tsv`에 탭으로 구분된 한 줄을 추가하세요.

## 참고

- 도쿄물리써클(東京物理サークル)의 공식 홈페이지는 아직 찾지 못했습니다. 과학교육연구협의회 도쿄지부의 [써클 안내 페이지](https://sites.google.com/view/ase-tokyo/%E3%82%B5%E3%83%BC%E3%82%AF%E3%83%AB)에 정기 모임 정보가 있습니다.
- 비슷한 성격의 자료: [아이치 물리써클 「いきいき物理わくわく実験」](http://ikiwakuphys2012.fan.coocan.jp/)
- 각 자료의 저작권은 원 저작자에게 있습니다. 수업 준비용 개인 참고 자료로만 사용하세요.
