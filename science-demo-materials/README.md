# 과학축전·데모 실험 자료 모음

물리 시범 실험과 체험 부스 아이디어를 모은 자료입니다. 일본 「청소년을 위한 과학제전(青少年のための科学の祭典)」과 국내 과학축제·교사 연수 자료집을 정리했습니다.
원본 PDF는 선생님 Google Drive의 「전국과학교사협회(k-sta.org)」 폴더에 있습니다. 여기에는 Drive에서 추출한 텍스트와 한국어 요약만 넣었습니다.

## 폴더 구성

- `summaries/`: 자료집별 한국어 요약입니다. 실험 목록 표, 분야, 원리, 준비물과 함께 고교 물리 수업에 쓸 만한 실험을 골라 두었습니다.
- `text/`: PDF에서 자동 추출한 원문 텍스트로, 검색용입니다. 줄바꿈과 순서가 원문과 다를 수 있습니다.
- `sources.tsv`, `scripts/download.sh`: 일본 쪽 공개 PDF의 다운로드 목록과 스크립트입니다. 지금 클라우드 환경에서는 접속이 막혀 있고, 네트워크를 허용하면 동작합니다.

## 알아 둘 점

- **도쿄물리써클(東京物理サークル)은 두 일본 자료집 어디에도 나오지 않습니다.** "동경과학축전" PDF는 「청소년을 위한 과학제전 전국대회」의 안내 책자입니다. 물리써클 이름은 참고문헌에 아이치·기후 물리써클의 『いきいき物理わくわく実験』이 한 번씩 나올 뿐입니다.
- Drive의 텍스트 변환은 큰 PDF를 앞쪽 약 80쪽까지만 돌려줍니다. 그래서 '제목만 있음'인 항목은 원본 PDF를 직접 열어 확인해야 합니다.
- 요약은 추출된 텍스트에 있는 내용만 옮겼습니다. 원문이 깨진 곳은 "(원문 불명확)"으로 표시했습니다. 원문의 물리 설명이 부정확한 곳은 요약 안에 주석을 달았습니다.
- 각 자료의 저작권은 원 저작자에게 있습니다. 수업 준비를 위한 개인 참고 자료로 사용하세요.

## つくばScience Edge (츠쿠바 사이언스 엣지)

츠쿠바 사이언스 엣지는 중·고등학생의 국제 과학 아이디어 콘테스트로, 2010년부터 매년 3월 츠쿠바 국제회의장에서 열립니다.
원본 PDF는 Drive 「전국과학교사협회(k-sta.org) › 츠쿠바사이언스엣지」 폴더에 있고, 공식 사이트는 [Report·要旨集 페이지](https://www.jtbbwt.com/files/user/ScienceEdge/report.html)입니다.
요약은 `summaries/tsukuba-science-edge/`에 있습니다. 각 요약에는 수상작 또는 발표 목록과, 물리 분야 연구 주제를 고교 탐구·R&E에 활용하는 아이디어를 넣었습니다.
