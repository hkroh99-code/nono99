# 2027학년도 수시 진학자료 (샘플: 서울대 · 연세대 · KAIST)

3학년 학생과 교사에게 나눠 줄 **대학별 1페이지(A4, 2단) 수시 안내자료**와 **기출문제 정리 폴더**다.
작성 기준일은 2026. 10. 13.이다. 원서접수가 끝난 시점이므로 **면접·발표 일정과 면접 대비**에 중점을 두었다.

## 폴더 구성

```
수시진학자료/
├── 01_서울대학교/
│   ├── 서울대_수시안내.pdf      ← 인쇄·배포용 1페이지
│   ├── 서울대_수시안내.html     ← 수정용 원본
│   ├── 조사노트_출처.md         ← 근거 자료, 출처 URL, (확인 필요) 항목
│   └── 기출문제/
│       ├── 기출문제_요약.md      ← 연도별 면접·구술 기출(물리·수학 중심) 요약과 공식 링크
│       ├── 다운로드목록.tsv      ← 원문 PDF 주소 목록
│       └── 원문/                 ← download_gichul.sh 실행 시 PDF 저장 위치
├── 02_연세대학교/  (같은 구성: 논술·면접 기출)
├── 03_KAIST/      (같은 구성: 학업역량 면접 기출)
├── assets/style.css             ← 공통 디자인(색·글꼴·2단 레이아웃)
└── tools/
    ├── render_pdf.py            ← HTML → A4 PDF 변환, 1페이지 여부 검사
    └── download_gichul.sh       ← 기출 원문 PDF 일괄 다운로드
```

## 각 안내자료에 담긴 항목

학교 소개 · 인재상(평가 방향) · 전형별 모집인원과 전형방법 · 수능최저 · 2027 변경사항 · 일정 · 면접(논술) 형태 · 물리 기출 경향 · 지도 체크포인트

## 기출문제 원문 받기

이 자료를 만든 클라우드 환경은 대학 사이트 접속이 차단되어 있어 PDF 원문을 직접 받지 못했다.
그래서 각 `기출문제/` 폴더에 **공식 링크와 문항 요약**을 정리했다. 학교 PC에서 아래 명령을 실행하면 원문이 `기출문제/원문/`에 저장된다.

```bash
bash 수시진학자료/tools/download_gichul.sh
```

게시판 첨부형 자료(서울대 2024~2026 면접·구술 문항 등)는 `다운로드목록.tsv`의 주석(#) 줄 주소를 브라우저로 열어 직접 받는다.

## 다른 대학 추가하기

1. `03_KAIST` 폴더를 복사해 `04_대학명`으로 만들고, HTML 파일 이름을 `대학명_수시안내.html`로 바꾼다.
2. 내용을 수정한다. 대학 색은 `<style>:root { --accent: #색상; }</style>` 한 줄로 바꿀 수 있다.
3. PDF를 만든다. 결과가 2페이지 이상이면 오류로 알려 준다.
   ```bash
   pip install playwright pypdf && playwright install chromium
   python3 수시진학자료/tools/render_pdf.py
   ```

## 주의

- 공식 PDF 원문을 직접 열람하지 못해 **검색으로 확인한 공식 자료 발췌와 언론·입시기관 보도를 교차 확인**해 작성했다.
  출처가 하나뿐이거나 출처마다 다른 수치는 안내자료에 `*` 또는 "확인 필요"로 표시했다. 상세 내용은 각 `조사노트_출처.md`에 있다.
- 배포 전에 다음 항목을 모집요강 원문으로 꼭 대조하자.
  - 서울대: 기회균형 인원, 사범대 반영비율
  - 연세대: 국제형·국제인재·기회균형 인원, 수능최저 세부, 1단계 발표일
  - KAIST: 일반전형 1단계 발표일(11.11)과 면접일(11.26)
