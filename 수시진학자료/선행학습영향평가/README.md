# 선행학습 영향평가 보고서 모음 · 기출 분석 (서울대 · 연세대 · 고려대 · KAIST)

각 대학 입학처가 공개한 「선행학습 영향평가 결과보고서」(2020~2026학년도)와 기출문항 원문을 모으고, 모집단위별 문항 정리와 분석을 덧붙였다.

- **먼저 읽기:** [종합분석_4개대학비교.md](종합분석_4개대학비교.md)
- 대학별 폴더 구성
  - `원문/`: 입학처에서 받은 보고서와 문항 PDF
  - `다운로드현황.md`: 연도별 파일, 원본 URL, 크기, 받지 못한 이유
  - `모집단위별_기출문항.md`: 연도별·모집단위(전형·과목)별 문항 요약, 출제의도, 교육과정 근거. 물리·수학은 원문에 가깝게 옮겼다
  - `분석.md`: 형식 변화, 단원 빈도표, 반복 주제, 지도 시사점

| 폴더 | 수집 연도 |
|---|---|
| 01_서울대학교 | 2020~2026 |
| 02_연세대학교 | 2021~2026 (2020은 입학처에서 삭제됨) |
| 03_고려대학교 | 2020~2026 |
| 04_KAIST | 보고서 2021~2026, 면접 기출 2020~2026 |

※ 원문 자료는 대학의 저작물이다. 「변형·발췌 금지」 조건이 있는 자료가 있으므로 교내 지도용으로만 쓰고 외부에 재배포하지 않는다.
