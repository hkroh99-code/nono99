# 서울대학교 면접 및 구술고사 기출문항 — 모집단위별 정리 (2020~2026학년도)

## 읽는 법

- **근거 자료:** `원문/` 폴더의 서울대 「선행학습 영향평가 결과보고서/자체평가보고서」(문항 분석 결과 요약표, 실무위원 검토의견)와 「수시모집 일반전형 면접 및 구술고사 문항」 PDF(문항 원문, 활용 모집단위, 문항해설, 출제의도, 교육과정 출제근거).
- **모집단위 매핑:** 각 학년도 보고서의 「문항 분석 결과 요약표」와 문항 PDF의 「활용 모집단위」 칸을 따랐다. 두 자료가 다르게 적힌 곳은 문항 PDF를 기준으로 하고 그렇다고 표시했다.
- **물리학·수학:** PDF에서 텍스트를 뽑은 뒤 한글 수식 폰트(HancomEQN/HyhwpEQ)의 사설 영역(PUA) 문자를 글리프를 렌더링해 확인하고 복원했다. 그래도 빠진 수식(예: 2024 수학C·D)은 페이지 이미지를 직접 보고 옮겼다. 분수·첨자는 한 줄 표기로 바꿨다(예: `v²/(4g)`, `I₁`). 그림에만 있는 값은 「그림 참조」로 표시했다. **원문은 「상업적 목적 사용 및 문서의 변형·발췌 금지」 문서이므로 이 파일은 교내 지도용으로만 쓴다.**
- **그 밖의 과목:** 제시문 요지, 각 문제가 묻는 것, 출제의도, 보고서에 적힌 교과/성취기준만 간추렸다.
- **교육과정 준수 여부:** 2020~2026 모든 학년도, 모든 문항이 요약표에서 「교육과정 준수 ○」로 판정되었다(아래에서 반복 표기하지 않음).
- 「적성·인성면접」(의대·치의학·수의대·간호대(2026)·사범대 교직적성)은 보고서가 「제출서류 혹은 적성·인성 기반 면접으로 선행학습 영향평가에서 문제 없음」으로 처리한 비교과 면접이다. 각 학년도 끝에 주제만 짧게 적었다.

### 수학 (교육과정 근거 2020-236호)
**수학 A [문제 1] — 상경군(+식품영양학과)·자유전공학부** (교과: 수학, 수학Ⅱ, 확률과 통계)
- 민호는 금 1g, 영희는 2g을 가진다. [규칙] (가) 민호가 투자량 a(0≤a≤1) g을 영희에게 준다. (나) 주사위를 던져 눈이 2 이하이면 영희가 투자량 1g당 (2+b) g을, 3 이상이면 (1−b) g을 민호에게 준다(b = 활성도, 0≤b≤1). [방식 1] 영희가 b를 먼저 공지한다. [방식 2] 민호가 a를 먼저 공지한다. 시행 후 보유량 X(민호), Y(영희)에 대해 평균 = 기대수익, 분산 = 위험도로 본다.
- 1-1. E(X), V(X)를 a, b로 구하라. 1-2. b가 공지되었을 때 U = E(X) − ½V(X)를 최대로 하는 민호의 최적 투자량 a. 1-3. a가 공지되었을 때 W = E(Y) − ½V(Y)를 최대로 하는 영희의 최적 활성도 b(여러 개면 모두). 1-4. (ㄱ) a는 b에 대한 민호의 최적 투자량이고 (ㄴ) b는 a에 대한 영희의 최적 활성도인 순서쌍 (a, b)를 모두 구하라.
- 출제의도: 이산확률변수의 평균·분산, 제한된 구간에서 이차함수의 최댓값(미분), 이차부등식, 미지수 2개인 연립이차방정식. ※ 1-4는 사실상 「서로 최적 대응인 쌍(내시 균형)」을 찾는 문제다(**해석**).

**수학 B [문제 1] — 수리군** (교과: 수학, 확률과 통계)
- 정의: (가) x, y, z의 단항식 a·xˡyᵐzⁿ과 다항식. (나) 대입값이 다르면 서로 다른 다항식. (다) 계수가 1인 단항식 xˡyᵐzⁿ을 기본 단항식이라 하고 차수는 l+m+n. (라) 어떤 다항식 q₁, q₂, q₃에 대해 r = p₁q₁ + p₂q₂ + p₃q₃로 나타나는 기본 단항식 r을 p₁, p₂, p₃의 「열매」라 한다. 예: p₁ = x²+3yz, p₂ = 7xz+4z², p₃ = 2xy일 때 x⁴ = (x²+3yz)x² + (7xz+4z²)(−xy) + (2xy)(2xz+2z²).
- 1-1. p₁ = 2x²−2xy−xz+yz, p₂ = 2xy−xz−2y²+yz, p₃ = 4xy−2xz−2yz+z²일 때, 차수 4인 기본 단항식 중 열매가 아닌 것의 개수. 1-2. p₁ = x²−y²+yz, p₂ = ax²+xz+y², p₃ = z²일 때, 열매가 아닌 기본 단항식이 무수히 많도록 하는 a. 1-3. p₁ = x²−y²+yz, p₂ = x²+xz+y², p₃ = z²의 열매 중 차수 4인 것을 모두 구하라.
- 출제의도: 인수분해와 중복조합으로 경우의 수 세기, 대우를 이용한 증명(필요충분조건), 다항식 사칙연산. ※ 내용상 다항식 아이디얼(ideal)의 단항식을 다루는 문제다(**해석**).

**수학 C [문제 1] — 수리군** / **수학 D [문제 1] — 공학군** (공통 소재; C의 교과: 수학, 확률과 통계, 미적분)
- 자연수 n과 −2n ≤ k ≤ 2n인 정수 k에 대해, 도둑이 한 번 움직일 때마다 (x, y)에서 (x+1, y+1) 또는 (x+1, y−1)로 가며, 원점에서 출발해 4n번 만에 (4n, 2k)에 도착한다. 경찰은 가능한 도주경로 하나를 같은 확률로 고르고, 그 경로가 (2n, 2n), (2n, 0), (2n, −2n) 중 하나를 지나면 단서를 발견한다.
- C: 1-1. n = 3, k = 0, 2, 4일 때 단서 발견 확률. 1-2. k = 2n−3일 때 확률 pₙ의 lim pₙ. 1-3. (n≥2) 확률을 최소로 하는 k를 모두 구하라. 1-4. 1-3의 k 중 가장 큰 값일 때 확률 qₙ에 대해 lim (1/n)·ln qₙ.
- D: 1-1, 1-2는 C와 같다. 1-3. k = n일 때 확률 qₙ에 대해 lim (1/n)·ln qₙ.
- 출제의도: 같은 것이 있는 순열과 수학적 확률(합·곱의 법칙), 수열의 극한, 계승·조합 부등식(C 1-3), **정적분과 급수의 관계(구분구적법)와 부분적분으로 ∫ln x dx 계산**(C 1-4 / D 1-3).

**수학 E [문제 1] — 자유전공학부(자연)·공학군** (교과: 수학, 수학Ⅱ)
- 양수 s에 대해 A(1, s), B(s+1, 0). (가) f(x) = k(x−a)+b (x ≤ a), (k+1)(x−a)+b (x > a)인 그래프를 「꺾인 선」이라 하고, k를 비탈, (a, b)를 꺾인 점이라 한다. (나) 양수 m에 대해 꺾인 선의 활성도는 m·a² + b.
- 1-1. A, B를 모두 지나는 꺾인 선의 비탈의 범위. 1-2. 그런 꺾인 선과 x축, y축으로 둘러싸인 도형의 넓이의 최솟값(s의 식). 1-3. s = 2일 때 「A, B를 지나는 꺾인 선 중 활성도가 최소인 것이 2개」가 되는 m을 모두 구하라.
- 출제의도: 두 점을 지나는 직선의 기울기와 교점, 주어진 구간에서 이차함수의 최솟값.

### 물리학 — 물리군 (교과: 통합과학, 물리학Ⅰ, 물리학Ⅱ / 2015-74호)
**문제 1 (전자기 유도 + 반도체)** — 근사 원문
> 서로 평행하고 가느다란 두 전도성 금속 레일이 지면에 대해 θ의 각도로 기울어져 있다. 레일 사이 간격은 L이고, 레일 사이 공간에는 지면에서 수직으로 나오는 균일한 자기장 B가 있다(빗면 고정, 중력가속도 g).
> **1-1.** 레일 위에 질량 M, 길이 L인 금속 막대를 지면과 수평하게 놓고 전원으로 전류 I₁을 흘리자, 고정장치를 풀어도 막대가 정지해 있었다(마찰 무시). I₁을 토막글①(자기장에 수직인 도선이 받는 힘 F = BIL)을 참고해 나타내라.

### 수학 (2020-236호)
**수학 A(인문) [문제 1] — 상경군** (교과: 수학, 수학Ⅰ, 수학Ⅱ) / **수학 D(자연) [문제 1] — 공학군(조경·바이오시스템·산림·약대)** (교과: 수학, 수학Ⅰ, 수학Ⅱ, 미적분)
- 앞면과 뒷면 모양이 영역 {(x, y) | x²/2 ≤ y ≤ 3/2}이고 앞뒤 간격이 1인 그릇에 물이 수면 높이 2/3까지 담겨 있다. 중심축이 y축과 이루는 각이 t(0 ≤ t ≤ π/2)가 되도록 기울일 때 수면 높이를 h(t)라 한다(물이 없으면 0).
- 1-1. h(t) = 0 ⇔ t₁ ≤ t ≤ π/2인 t₁. 1-2. 물의 양이 기울이기 전과 같을 필요충분조건이 0 ≤ t ≤ t₀인 t₀. 1-3. h(t)를 t의 식으로 구하고, cos t₂ = 2√7/7일 때 h(t₂). (D만) 1-4. (0, π/2)에서 h(t)의 미분가능성을 논하라.
- 출제의도: 접선과 탄젠트, 정적분 넓이, 점과 직선 사이 거리, 삼각함수, 미분계수로 미분가능성 판정(D).

**수학 B(자연) [문제 1] — 자유전공학부(자연)** (교과: 수학, 수학Ⅱ, 확률과 통계)
- X: [−5, 5]에서 연속이고 각 [k, k+1]에서 기울기 ±1인 일차함수이며 f(−5) = f(5) = 0인 함수의 집합.
- 1-1. |X|. 1-2. f(x) ≤ x² + 2를 만족하는 함수의 집합 Y의 원소 개수. 1-3. Y의 원소 f에 대해 ∫₋₅⁵ f(x) dx의 최댓값. 1-4. g(x) = −(x+2)² + 2, h(x) = (x−2)² + a의 그래프 어느 것과도 만나지 않는 f ∈ X가 존재하는 a를 모두 구하라.
- 출제의도: 같은 것이 있는 순열, 판별식(이차함수와 직선), 정적분.

**수학 C(자연) [문제 1] — 수리군** / **수학 D(자연) [문제 2] — 공학군** (교과: 수학, 수학Ⅱ, 미적분, 기하)
- 원 Aₙ: 중심 (n, 0), 반지름 √n. 자연수 m에 대해 직선 l은 (−m, 0)을 지나고 기울기가 a다.
- 1-1. l이 Aₙ과 만나는 a²의 범위(m, n). 1-2. l이 A₁, A₂, … 중 정확히 하나와 만나는 a²의 범위. 1-3. 어떤 자연수 k에 대해 (−k, 0)과 P를 지나는 직선이 원들 중 하나와 P에서만 만나고 나머지와는 만나지 않을 때 P를 「좋은점」이라 한다. 모든 좋은점과, 그 점들을 모두 지나는 이차곡선을 구하라.
- 출제의도: 원과 직선의 위치 관계(판별식), 유리함수의 도함수로 최댓값 찾기, 접점과 이차곡선(포물선).

**수학 C(자연) [문제 2] — 수리군** (교과: 수학, 수학Ⅱ)
- 다항식 P(x)를 P(x) = xᵏQ(x) (Q(0) ≠ 0)로 나타낸다.
- 2-1. 0 < |x| < 1에서 5x⁵ − 4x⁴ + x³의 부호. 2-2. 「0 < |x| < 1이면 P(x) > 0」인 다항식에서 가능한 k를 모두 구하라. 2-3. 0 < x < 1에서 P₁ > P₂ > 0일 때 k₁, k₂의 대소. 2-4. (가) 0 < x < 1에서 0 < P₁ < P₂ < P₃이고 (나) −1 < x < 0에서 P₁ < P₃ < 0 < P₂인 P₁, P₂, P₃이 존재할 수 있는지 논하라.
- 출제의도: 인수분해와 개형, 극한·연속성과 귀류법을 이용한 증명.

### 물리학 — 물리군
**문제 1 (볼록렌즈 · 현미경 · 초점심도)** — 근사 원문 (보고서 교과: 물리학Ⅱ)
> 모든 문제에서 렌즈 방정식을 쓸 수 있고 렌즈 두께는 무시한다.
> **1-1.** 초점거리 f = 6 cm인 볼록렌즈가 O에 있고, O에서 8 cm 떨어진 점 A에서 y 방향 3 cm인 물체 a와 x 방향 2 cm인 물체 b가 시작된다. 광선 추적과 렌즈 방정식으로 각 상의 시작점 위치, 크기, 방향, 실상/허상을 구하라.
> **1-2.** 초점거리 f, 지름 D인 렌즈로 아주 작은 발광 물체가 점 A에 있을 때 스크린(렌즈에서 b)에 또렷한 상이 맺힌다. 물체를 +x 방향으로 옮기면 스크린에 원형 상이 생기는데, 지름이 l 이하이면 또렷하게 인식된다. 여전히 또렷하게 보이는, A에서 가장 먼 물체의 좌표를 b, f, l, D로 나타내라(a > f, D > l).
> **1-3.** 두 볼록렌즈로 만든 현미경: 물체 AB가 대물렌즈 초점거리 f_o 바로 바깥에 있을 때 접안렌즈 초점거리 f_e 바로 안쪽에 첫 상이 맺히고, 접안렌즈가 거리 D에 확대된 상을 만든다. 접안렌즈 중심과 눈 사이 거리가 L_e일 때 배율을 f_o, f_e, L, L_e, D로 나타내라(전체 배율 = 각 배율의 곱).
> **1-4.** 두 볼록렌즈로 아주 작은 물체의 상을 관찰한다. 상의 지름이 l = 80 μm 이하이면 또렷하게 보인다. 물체가 A에 있을 때 상이 또렷하다. 물체를 −x 방향 무한히 먼 곳에서 A를 향해 옮길 때, 상의 지름이 l이 되는 순간 물체와 A 사이 거리를 유효숫자 1자리로 구하라(렌즈 값은 그림 4 참조, |β| ≪ 1이면 1/(1−β) ≃ 1+β).
- 출제의도: 렌즈 방정식과 광선 추적, 도립·정립상, 배율, 두 렌즈 광학기기에서 상의 형성(초점심도 개념; **해석**).

**문제 2 (보어 모형의 중력판 · 케플러 · 도플러로 블랙홀 찾기)** — 근사 원문 (교과: 물리학Ⅰ, 물리학Ⅱ)
> 수소 원자(전기력 결합), 태양 둘레의 지구, 블랙홀 둘레의 별(중력 결합)을 비교한다. 상수표: c = 3.0×10⁸ m/s, h = 6.6×10⁻³⁴ J·s, G = 6.7×10⁻¹¹, k = 9.0×10⁹, e = 1.6×10⁻¹⁹ C, mₑ = 9.1×10⁻³¹ kg, m_p = 1.7×10⁻²⁷ kg, M_⊙ = 2.0×10³⁰ kg, M_⊕ = 6.0×10²⁴ kg, r_p = 1.0×10⁻¹⁵ m, a₀ = 5.3×10⁻¹¹ m. 수치는 유효숫자 1자리.
> **2-1.** 전자와 양성자의 전하가 10,000배가 되면 보어 모형의 궤도 반지름은? 물리적으로 가능한가(전자는 점입자)?
> **2-2.** 지구 공전에 보어 모형을 적용(쿨롱 대신 중력)해 「보어 반지름」을 구하고, 궤도 반지름이 1 AU = 1.5×10¹¹ m가 되는 양자수 N과 N+1, N 상태의 반지름 차이를 구하라.
> **2-3.** 수소 전자의 궤도 속력이 1/2배가 되면 궤도 반지름은 몇 배인가? 빛을 흡수했는가 방출했는가? 그 진동수는?
> **2-4.** 1 AU 원궤도의 지구 속력이 갑자기 1/2배가 되면 타원궤도로 운동한다(r₁v₁ = r₂v₂). 원일점·근일점 거리와 주기를 구하라(중력 퍼텐셜은 −GMm/r 형태, mgh 사용 금지).
> **2-5.** 블랙홀(M ≫ m) 둘레를 속력 v, 주기 T로 도는 별의 빛을 지구에서 관측한다(시선이 궤도면 위, 빛은 속력 c인 음파처럼 다룬다, (1+x)ⁿ ≃ 1+nx). 진동수의 시간 변화를 정량적으로 기술하고, 블랙홀의 존재와 질량을 어떻게 알아낼 수 있는지 설명하라.
- 출제의도: 보어 모형과 원자의 안정성, 다른 상황에 적용, 에너지 준위와 광자, 케플러 법칙과 역학적 에너지로 타원궤도 기술, 천체 운동의 도플러 효과.
