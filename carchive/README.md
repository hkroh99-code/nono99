# 🚗 Car-chive — 중고차 점검 사진 아카이브

중고차 점검(하자·수리·침수 확인) 사진을 **차종·부위·하자 유형**으로 분류해 쌓고, 찾아보고, “이 차종은 어디가 잘 문제 되나?”를 통계로 보는 프로그램입니다.
기획서(`기획서_원본.pdf`)의 구조(Streamlit + SQLite + Pillow, 4대 분류, 4개 화면)를 그대로 구현하고, 현업에서 필요할 만한 기능을 더 얹었습니다.

## 실행 (처음 한 번만 설치)
- **Windows**: `run.bat` 더블클릭 (Python 3.10+ 설치 필요) 
- **Mac/Linux**: `./run.sh`
- 직접 실행: `pip install -r requirements.txt` → `streamlit run app.py` → 브라우저에서 열림
- 데이터는 `data/` 폴더에 저장됩니다(사진·썸네일·DB). 다른 위치를 쓰려면 환경변수 `CARCHIVE_DATA=경로`.
- 사내 여러 명이 쓰려면 한 PC(또는 서버)에서 실행하고 `streamlit run app.py --server.address 0.0.0.0` 로 열어 같은 네트워크에서 접속합니다. **로그인 기능은 없으므로** 사내망에서만 쓰세요.
- 처음 켜면 비어 있습니다. 대시보드의 「🧪 데모 데이터 불러오기」로 합성 이미지 약 70장을 넣어 체험하고, 「데이터 관리 › 데모 데이터」에서 한 번에 지울 수 있습니다.

## 화면
| 메뉴 | 하는 일 |
|---|---|
| 📊 대시보드 | 전체 현황, 많이 나온 하자 TOP10, 부위·차종별 통계, 등록 추이, 최근 사진 |
| 📤 사진 등록 | 차량(기존/신규) 선택 → 사진 여러 장 → 공통 태그·코멘트. 중복 사진 자동 감지 |
| 🏷️ 분류 대기함 | 태그 없이 올린 사진을 한 장씩 빠르게 분류(저장→다음 / 건너뛰기 / 정상 사진 표시) |
| 🔎 검색·갤러리 | 제조사·차종·연식·주행거리·부위·하자·심각도·점검자·기간·글자·💧침수 관련 다중 필터, 검색 결과 CSV |
| 🚘 차종별 취약 리포트 | 차종(+연식 범위)별 하자 발생 차량 비율·심각도·주행거리, 대표 사진, 차종×부위 히트맵, 침수 의심 모아보기 |
| 🧩 분류체계 관리 | 부위·하자 항목 추가/이름 변경/숨김(코드 수정 불필요). 침수 관련 표시 지정 |
| 💾 데이터 관리 | 전체 CSV 내보내기, zip 백업, 차량 정보 일괄 수정, 휴지통(복구/영구삭제), 데모 데이터 |

사진 상세 팝업: 큰 사진 + 태그(여러 개·심각도·메모) 편집, 코멘트, **결함 위치 네모 표시**(원본은 그대로), 같은 하자의 비슷한 사례(같은 차종 우선), 차량 정보 수정, 원본 내려받기.

## 기획서에서 업그레이드한 점
1. **심각도(경미/주의/심각)** — 태그마다 지정. 리포트에서 평균 심각도·‘심각’ 건수 집계.
2. **침수 전용 관점** — 침수 관련 항목(진흙/모래, 청록 산화, 물때, 안전벨트 끝단 등)에 💧 표시, 침수 의심 모아보기·필터·대시보드 카운트.
3. **“차량 수” 기준 통계** — 사진 장수가 아니라 ‘그 차종 N대 중 M대에서 발견’(발생률)로 계산해 사진을 많이 찍은 차량이 통계를 왜곡하지 않게 했습니다. 표본이 5대 미만이면 경고.
4. **분류 대기함** — 현장에서 일단 막 올리고 나중에 분류하는 흐름 지원. 하자 없는 정상 부위 사진은 ‘비교용(정상)’으로 표시.
5. **중복 사진 방지**(파일 해시), 삭제는 **휴지통** 경유, 이미지 형식 검사(HEIC 안내), EXIF 촬영일 자동 저장.
6. **결함 위치 박스**(기획서의 “향후 OpenCV로 네모 박스”를 수동 방식으로 먼저 구현 — 슬라이더로 위치 지정).
7. **분류체계를 DB화** + 관리 화면. 기본 분류는 기획서 4대 분류 + 전기차/하이브리드, 타이어/휠을 추가해 중분류 약 30개·하자 항목 76개로 시작.
8. 차량 테이블 확장(트림·연료·차량번호·차대번호·메모), 내보내기·백업·테스트(`python3 -m unittest test_core`).
- 기획서의 Firebase(NoSQL) 안은 쓰지 않고 SQLite(관계형)로 했습니다. 설치·비용·보안 부담이 없고 한 파일로 백업되며, 다대다(사진↔하자) 통계에도 유리합니다. 나중에 여러 지점이 함께 쓰게 되면 PostgreSQL + 클라우드 저장소로 옮기는 것이 다음 단계입니다.

## 파일 구성
`app.py` 화면 · `db.py` 저장/검색/통계 · `imaging.py` 이미지 처리 · `taxonomy.py` 기본 분류 · `demo.py` 체험 데이터 · `test_core.py` 테스트

## 알아둘 점
- 차량번호·차대번호는 개인정보입니다. 꼭 필요할 때만 입력하고 `data/`와 백업 파일을 안전하게 보관하세요.
- 분류체계의 기본 항목과 침수 관련 표시는 일반적인 점검 상식에 따른 **초기안**입니다. 회사 점검 기준에 맞게 「분류체계 관리」에서 고쳐 쓰세요. 침수·사고 여부의 최종 판단은 점검자의 종합 판단이며 이 프로그램은 자료 정리 도구입니다.
- 사진은 서버가 아니라 이 PC의 `data/photos` 에 저장됩니다. **백업을 정기적으로** 받으세요.
