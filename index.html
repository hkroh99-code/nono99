학생이 CERN 과학자처럼 실험하는 교실

원자 속을 들여다본 러더퍼드에서 시작해, 가속기와 검출기를 직접 다뤄 보고, 마지막에는 CMS 실험의 실제 충돌 데이터로 Z 보손과 힉스 보손의 흔적을 찾습니다. 주제마다 학교에서 할 수 있는 실물 실험과 3D 모의실험이 짝을 이룹니다.

사용법

수업에서 이렇게 씁니다

1. 교사용 지도서로 준비

분 단위 수업 흐름, 준비물과 구입처, 안전 지도, 예시 결과와 정답·해설, 평가 루브릭이 들어 있습니다.

2. 학생용 활동지로 실험

화면에서 바로 답을 입력하면 기기에 자동 저장됩니다. 제출할 때는 [내 답안 복사]로 LMS나 클래스룸에 붙여 넣습니다. 인쇄해서 써도 됩니다.

3. 3D 모의실험으로 탐구

미션을 해결하면 자동으로 완료 표시가 됩니다. 측정값은 기록표에 쌓이고, [표 복사]로 스프레드시트에 붙여 넣어 분석합니다.

4. 실제 데이터로 마무리

주제 10에서는 CMS가 2011~2012년에 기록한 실제 충돌 사건을 분석합니다. 학생이 CERN 오픈데이터 포털에서 직접 내려받는 방법도 안내합니다.

설치 없이 동작합니다. 모든 자료는 HTML 파일이라 웹 브라우저(크롬, 엣지, 사파리, 웨일)로 열면 됩니다. 3D 엔진과 실제 데이터가 저장소 안에 들어 있어서, 인터넷이 불안정한 교실에서도 폴더째 내려받아 쓸 수 있습니다.
