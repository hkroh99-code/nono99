발명 ①고등POE🛠 프로젝트 공방 ⑤ 발명 1~5
🎯 이 공방에서 하는 것 — 저가 풍속계 · 벤투리 환기구 · 페트병 벤투리 유량계 · 절수 샤워 노즐 · 사이펀 자동 급수기 5개 발명 프로젝트입니다(I01 ~ I05). 「불편 찾기 → 설계 계산 → 시제품 → 성능 시험 → 명세서」의 발명 사이클을 따르며, 모든 시제품은 저전압 전자 부품 · 물 · 저속 바람만 씁니다. 안전 : 이 공방의 모든 활동은 저속 선풍기 · 헤어드라이어(냉풍 · 약풍) · 물 · 빨대 · 주사기 · 저울만 쓰는 안전한 실험입니다(고압 공기 · 연소 · 가열 · 압축 가스 · 고속 회전체는 쓰지 않습니다).
🧭 선행조직자 — 발명은 「작은 문제 + 숫자 하나」에서
발명은 거창한 것이 아니라 일상의 작은 불편 하나를 숫자로 줄이는 일입니다. 풍속계의 오차(분해능), 환기 횟수, 유량 읽기 오차, 절수율, 급수 시간 — 각 발명에는 성공을 가르는 성능 숫자 하나가 있고, 그 숫자를 식으로 예측해 시제품으로 확인합니다.
문제 찾기→설계 계산→시제품→성능 시험→명세서
🧭 공방 안내 — 이렇게 진행합니다 중등부터
그림 12-1. 발명 의 흐름 — 여섯 단계를 거치며 되돌아가 고치는 것이 핵심이다
🧰 이 공방의 도구와 역할
① 문제 정의누가 어떤 불편을 겪는가.
② 설계 식$\Delta p=\tfrac12\rho v^2$ · $Q=A v$ 등으로 숫자 계산.
③ 시제품작고 값싼 재료.
④ 성능 지표정확도 · 분해능 · 응답 시간.
⑤ 안전 설계저전압 · 방수 · 회전체 보호.
⑥ 한계 서술어떤 조건에서 실패하는가.
🧪 진행 순서
불편 찾기 — 주변의 불편 · 위험을 3 가지 적는다.
설계 계산 — 필요한 압력 · 유량 · 속력을 식으로 계산한다.
시제품 — 가장 작은 것부터(빨대 · 호스 · 센서).
성능 시험 — 조건을 바꿔 가며 숫자로 기록한다.
발명 설명서 — 새로운 점 · 한계 · 안전 대책을 쓴다.
🔧 쉽게 이해하기 — 열쇠고리 손전등
작은 열쇠고리 손전등은 어두운 열쇠 구멍이라는 아주 작은 불편에서 나왔지만 모두가 씁니다. 발명은 작은 문제 → 계산 → 시제품 → 성능 숫자의 사이클이에요. 성능 숫자를 먼저 약속하면 실험이 곧 시험이 됩니다.
❌ 이렇게 생각하기 쉬워요“발명은 복잡한 장치를 만들어야 한다.”
✅ 실제로는문제 → 계산 → 시제품 → 성능 숫자의 사이클을 지키면 작은 장치도 훌륭한 발명이 됩니다.
