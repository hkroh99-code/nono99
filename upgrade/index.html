20시간 너머로: 확장 모듈

기본 20시간 수업에서 배운 가속·검출·불변질량·데이터 분석을 코딩, 의학, 우주의 수수께끼, 학생 연구로 넓히는 확장 모듈입니다. 학교 사정에 맞게 골라 쓰고, 새 주제를 더해 키워 갈 수 있습니다.

01

여기서 말하는 "업그레이드"

이 자료의 기본과정은 10개 주제 × 2차시 = 20시간입니다. 업그레이드는 그 위에 얹는 세 가지 층을 말합니다.

1. 확장 모듈 (U1~U6)

이 페이지의 모듈. 기본 주제 하나 이상과 이어지며, 한 모듈은 2~4차시 분량입니다. 기본과정을 마친 뒤 이어서 하거나, 관련 주제 바로 뒤에 끼워 넣어 함께 운영할 수 있습니다.

2. 주제별 업그레이드 도전

각 학생용 활동지 끝의 "업그레이드 도전" 상자. 빨리 끝낸 학생, 심화 과제, 수행평가 가산 과제로 씁니다. 수업 시간을 늘리지 않습니다.

3. 교사가 키우는 자료

새 주제나 모듈을 더하는 것. 모든 페이지가 같은 틀(templates/)과 설계서(docs/curriculum-spec.md)를 따르므로, 아래 정책대로 추가하면 내비게이션과 저장 기능이 그대로 작동합니다.

모듈 페이지 구성 — 모든 모듈 페이지는 앞부분이 학생 활동(입력칸 자동 저장, [내 답안 복사] 가능), 끝부분이 접힌 상자 "교사용 안내 (정답·운영 팁)"입니다. 학생에게 화면을 보여 줄 때는 교사용 상자를 펼치지 마세요. U6은 교사용 설계 자료입니다.

끼워 넣기 vs 이어 하기

  • 끼워 넣기: 연결 주제 바로 뒤에 1~2차시로 압축해 넣습니다. 예) 주제 7 다음에 U2 1차시(쌍소멸과 운동량 보존만).
  • 이어 하기: 20시간을 마친 뒤 2~4차시 모듈로 운영합니다. 학기 말, 시험 뒤 기간에 알맞습니다.
  • U1·U5는 학생 과제 시간이 필요하므로 2주 이상 간격을 두고 운영하면 좋습니다.

05

버전·업그레이드 정책

이 자료는 빌드 과정이 없는 정적 HTML입니다. 파일을 고치고 브라우저로 열면 바로 반영됩니다. 여러 교사가 함께 고쳐도 모양과 기능이 흐트러지지 않도록 아래 규칙을 따릅니다.

버전뜻예
v1.0기본 20시간(주제 1~10) + 업그레이드 U1~U6현재 구성
v1.x내용 보완, 업그레이드 모듈 추가(기존 주제 번호는 그대로)U7 "가속기와 문화재 분석" 추가
v2.0주제 구성이나 차시 구조 자체를 바꿈주제 11 추가, 주제 순서 변경

새 기본 주제를 추가하는 방법 (예: 주제 11)

  1. 설계 먼저 — docs/curriculum-spec.md 3절 형식(핵심 질문 / 학습 목표 / 실험 A / 실험 B(3D) / CERN 연결 / 업그레이드 도전)으로 설계를 적습니다. 수치는 2절 "자주 쓰는 정확한 값" 표를 따르고, 표에 없는 값은 출처를 확인합니다.
  2. 틀 복사 — templates/student.html → students/t11.html, templates/teacher.html → teachers/t11.html, templates/sim.html → sims/t11.html. 파일 안의 NN을 11로, __…__ 자리를 내용으로 바꿉니다. body의 data-topic="11"을 꼭 고칩니다.
  3. 목록 등록 — assets/js/common.js의 TOPICS 배열 끝에 한 줄을 더합니다. 이 배열이 이전/다음 링크의 유일한 출처입니다.
  4. 지도 고치기 — 첫 화면 index.html의 차시 지도와 각 목록 페이지(students/, teachers/, sims/의 index)에 링크를 더합니다.
  5. 기록 — CHANGELOG.md에 날짜, 버전, 바꾼 내용, 작성자를 적습니다.
  6. 점검 — 아래 점검 목록을 확인하고, 휴대전화 폭(약 400 px)에서도 가로 스크롤이 생기지 않는지 봅니다.
// assets/js/common.js
var TOPICS = [
  …,
  { n: 10, level: "int", title: "실제 CERN 데이터로 발견하기", short: "실제 데이터 분석", hours: 2 },
  { n: 11, level: "int", title: "새 주제 제목", short: "짧은 이름", hours: 2 }   // ← 추가
];
// level: "basic"(기본과정) · "adv"(심화과정) · "int"(종합과정)

새 업그레이드 모듈을 추가하는 방법 (예: U7)

  1. 가장 비슷한 모듈 페이지(예: upgrade/u3.html)를 복사해 upgrade/u7.html로 저장합니다. body는 data-page="upgrade" data-root="../"를 유지합니다.
  2. 학생 활동은 <main class="page worksheet"> 안에 두고, 모든 입력칸에 페이지 안에서 겹치지 않는 id와 라벨을 붙입니다(자동 저장의 열쇠).
  3. 정답과 운영 팁은 맨 끝 <details> "교사용 안내 (정답·운영 팁)"에 넣습니다.
  4. 이 페이지의 모듈 목록과 운영 표에 한 줄씩 더하고, 모듈 페이지 아래의 이전/다음 링크를 고칩니다.

작성 점검 목록

여러 교사가 함께 고칠 때

  • 공통 파일(assets/, templates/, docs/)은 한 사람이 맡아 고치고, 바꾼 내용을 CHANGELOG에 남깁니다.
  • 데이터(data/)는 원본 CSV를 바꾸지 않습니다. 가공한 데이터는 새 파일 이름으로 더하고 출처를 적습니다.
  • 학생 답안은 각자의 브라우저에만 저장되므로, 파일을 고쳐도 학생 답안은 지워지지 않습니다. 단 입력칸의 id를 바꾸면 그 칸의 저장 답안은 다시 보이지 않습니다.
