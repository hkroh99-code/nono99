# CERN 탐구 교실 — 교육과정 설계서 (제작·업그레이드용)

이 문서는 자료를 새로 만들거나 고칠 때 따르는 기준입니다. 모든 페이지는 이 설계서와 `templates/`의 틀을 따릅니다.

## 1. 전체 구조

- 대상: 고등학교 2~3학년(물리학 이수 중이거나 이수한 학생). 기본과정은 1학년도 가능.
- 총 20시간 = 10개 주제 × 2차시(50분). 차시는 주제마다 압축(1차시)·확장(3차시)할 수 있다.
- 단계: 주제 1~5 기본과정(기본·보통), 6~7 심화과정, 8~10 종합과정(여러 개념을 합쳐 실험·설계·분석).
- 마지막 주제 10은 CMS 실제 오픈 데이터(2011~2012년 충돌 데이터)로 분석한다.
- 주제마다 세 가지 자료: 학생용 활동지 `students/tNN.html`, 교사용 지도서 `teachers/tNN.html`, 3D 모의실험 `sims/tNN.html`.
- 업그레이드 트랙: `upgrade/` 확장 모듈(U1~U6)과 주제별 "업그레이드 도전".

## 2. 공통 작성 규칙

- 언어: 한국어. 고등학생이 읽을 수 있는 문장. 짧고 분명하게. 물리 용어는 교과서 용어(운동량, 전기장, 자기장, 로렌츠 힘, 불변질량 등).
- 교육과정 연계는 **과목·단원 이름으로만** 쓴다(예: "물리학 – 힘과 운동", "전자기와 양자 – 전자기장"). 성취기준 코드는 지어내지 않는다.
- 숫자·사실은 정확하게. 확실하지 않은 최신 수치(회원국 수 등)는 "20여 개 회원국"처럼 범위로 쓴다.
- 꾸밈용 이모지 금지. 색은 CSS 변수만 사용(학생/교사 페이지). 인라인 SVG는 `currentColor`, `var(--accent)`, `var(--track)`, `var(--ink-3)` 등 사용.
- 학생 페이지의 모든 입력칸에는 고유 `id`(예: `lab-a1`)와 라벨(span 또는 aria-label)이 있어야 한다. `.worksheet` 안의 입력은 자동 저장된다.
- 3D 모의실험은 `assets/js/sim-kit.js`의 API만 사용하고, three.js는 `assets/vendor/three/`(r147, 전역 `THREE`, `THREE.OrbitControls`)를 쓴다. ES 모듈 금지(로컬 파일로 열어도 동작해야 함). 외부 네트워크 요청 금지(구글 폰트 링크만 예외).
- 입자 색은 `SimKit.COLORS`를 따른다: 전자 파랑, 뮤온 분홍, 광자 노랑, 강입자/제트 주황, 중성미자 회색 점선, 양성자 빨강.
- 모의실험은 열자마자 무언가 움직이거나 보이는 상태(빈 화면 금지). 미션 3~5개, 측정값, 기록표(Recorder), 필요하면 그래프(SimKit.plot).
- 모의실험 단위는 화면에 명시. 장면 축척이 실제와 다르면 "화면 축척: 1칸 = …" 같은 안내를 HUD에 쓴다.

### 주제 1. CERN과 물질의 기본 구성 (기본과정)
- 핵심 질문: 세상을 이루는 가장 작은 조각은 무엇이고, 보이지 않는 것을 우리는 어떻게 알아내는가?
- 목표: 물질의 계층(분자→원자→핵→핵자→쿼크)과 크기 규모(10⁻¹⁵ m 등)를 설명한다 / 표준모형의 페르미온(쿼크 6, 렙톤 6)과 보손(매개 입자, 힉스)을 분류한다 / 간접 관측으로 내부 구조를 추론하는 과학 방법을 경험한다. CERN이 무엇을 하는 곳인지(1954년, 국제 협력, WWW) 소개한다.
- 실험 A: **블랙박스(미스터리 상자) 탐구** — 상자 속 숨은 모양을 막대 찌르기·구슬 굴리기·흔들기 소리로 추론, 모둠별 추론 그림 → 과학자처럼 모형 세우기. 보충: 종이띠 크기 규모 만들기(10의 거듭제곱).
- 실험 B(3D) `sims/t01.html`: **물질 속으로 줌인** — 물방울→물 분자→산소 원자(전자 구름)→원자핵→양성자(쿼크 3개 + 글루온)로 단계별 확대(스크롤/버튼). 각 단계 크기(m)와 10의 거듭제곱 표시. 두 번째 모드: **표준모형 3D 갤러리** — 17개 기본 입자를 3D 카드/구로 배치, 클릭하면 질량·전하·스핀·발견 연도 정보. 미션: 크기 비율 계산(원자/핵 ≈ 10⁵), 양성자의 쿼크 조합(uud)으로 전하 계산, 중성자(udd) 만들기 퍼즐.
- 업그레이드: 반물질 입자(반쿼크)로 반양성자 만들기, 쿼크 조합으로 π⁺, K⁻ 등의 전하 계산.

### 주제 2. 러더퍼드 산란: 보이지 않는 핵을 보는 법 (기본과정)
- 핵심 질문: 직접 볼 수 없는 원자핵의 크기를 어떻게 측정했을까? 그 방법은 LHC와 어떻게 이어지는가?
- 목표: 톰슨 모형과 러더퍼드 모형의 예측 차이를 설명 / 충돌 매개변수와 산란각의 관계 / 확률(명중률)로 표적의 크기를 추정 / "입자를 충돌시켜 내부를 본다"는 CERN의 기본 아이디어 연결.
- 실험 A: **구슬 산란 실험(확률로 크기 재기)** — 판 아래 숨긴 원판(또는 블록) 표적들 사이로 구슬을 무작위로 굴려 명중 비율 → 표적 지름 추정: 명중률 P = N·d / W (N개 표적, 지름 d, 폭 W). 실제 자로 잰 값과 비교, 시행 횟수와 오차.
- 실험 B(3D) `sims/t02.html`: **금박 산란실** — 알파 입자 빔을 금 원자핵에 발사(쿨롱 반발 수치 적분), 충돌 매개변수 b·알파 에너지·표적 전하 Z 조절, 원형 검출 스크린에 산란각 기록, 산란각 히스토그램과 러더퍼드 공식(∝ 1/sin⁴(θ/2)) 비교. 톰슨 모형 토글(퍼진 양전하 → 거의 안 휨). 미션: b가 작을수록 θ가 큼 확인, 180° 가까운 되튐 관찰, 에너지 2배일 때 가장 가까운 접근 거리 변화(d = kZ·2e²/E_k) 측정.
- 업그레이드: 가장 가까운 접근 거리로 금 핵 반지름의 상한 계산, 전자 산란(호프스태터)로 양성자 크기 측정 이야기.

### 주제 3. 전기장으로 입자 가속하기 (기본과정)
- 핵심 질문: 입자를 거의 빛의 속력까지 가속하려면 전기장을 어떻게 써야 할까?
- 목표: 전위차 V에서 전하 q가 얻는 에너지 qV, 전자볼트(eV) 정의 / 직류 가속의 한계와 교류(RF) 공동 가속 원리 / 드리프트 튜브 길이가 점점 길어지는 이유(속력 증가) / CERN 가속 사슬 첫 단계 Linac4.
- 실험 A: **정전기 가속과 에너지 계산** — (1) 풍선/반데그라프 발전기로 대전체가 가벼운 물체를 당기고 밀기 관찰, (2) 경사로 계단 모형: 계단(전위차)마다 구슬이 얻는 속력을 영상·초시계로 측정, 높이 h ↔ 전위차 V 비유(mgh ↔ qV), 계단을 많이 거칠수록 에너지 증가 → 선형가속기 비유. 계산 활동: 1 V로 가속된 전자의 에너지 1 eV = 1.6×10⁻¹⁹ J, 1 kV로 가속된 전자의 속력.
- 실험 B(3D) `sims/t03.html`: **선형가속기 위상 맞추기** — 원통형 드리프트 튜브가 줄지어 있고 RF 전압이 교대로 바뀜. 학생이 주파수·전압·튜브 길이 배치를 조절해 양성자 묶음이 매 간극마다 가속되게 맞추기. 위상이 어긋나면 감속. 비상대론/상대론 속력 표시(γ). 미션: 위상 맞추기 성공, 간극 수 대비 운동 에너지 그래프(직선), 튜브 길이 L = v/(2f) 확인, 에너지가 커지면 속력이 c에 가까워져 튜브 길이 증가가 멈춤을 관찰.
- 업그레이드: 상대론적 운동에너지(γ−1)mc²로 Linac4 출구 속력(160 MeV 양성자 → 약 0.52c) 계산.

### 주제 4. 자기장으로 입자 휘기 (기본과정)
- 핵심 질문: LHC는 왜 둥글고, 왜 그렇게 강한 자석이 필요할까?
- 목표: 로렌츠 힘 F = qvB의 방향(오른손 법칙)과 크기 / 등속 원운동 반지름 r = mv/(qB) = p/(qB) / 속도가 B와 비스듬하면 나선 운동 / p[GeV/c] = 0.3·B[T]·r[m]로 LHC 자석 세기 추정.
- 실험 A: **로렌츠 힘 그네(전류 그네) 실험** — 네오디뮴 자석 사이에 매단 알루미늄 포일(또는 구리선 그네)에 건전지 전류를 흘려 힘의 방향 관찰, 전류·자석 방향을 바꿔 오른손 법칙 확인, 자석 개수(B)와 전류에 따른 흔들림 정도 비교. 보충: 음극선관(있는 학교)에서 자석으로 전자빔 휘기.
- 실험 B(3D) `sims/t04.html`: **자기장 속 하전 입자 궤적** — 균일한 B 영역에 입자(전자, 양성자, 뮤온, 알파) 발사. q, m, v, B, 입사각 조절. 원 궤도 반지름 자동 측정 + 이론값 비교, 나선 운동, 힘 벡터 화살표 표시. 두 번째 모드: **싱크로트론 링** — 링 반지름 고정, 빔 에너지를 올릴 때 B를 함께 올리지 않으면 빔이 벽에 부딪힘(B 램프 맞추기 게임). 미션: r ∝ v, r ∝ 1/B 확인(그래프), 전자와 양성자 반지름 비교, LHC(r≈2.8 km, 6.8 TeV)에 필요한 B 계산 ≈ 8 T.
- 업그레이드: 사이클로트론 주기 T = 2πm/(qB)가 속력과 무관함 확인, 질량 분석기 원리.

### 주제 5. 입자 검출기: 보이지 않는 흔적 찾기 (기본과정)
- 핵심 질문: 너무 작고 빨라 볼 수 없는 입자를 검출기는 어떻게 "보는가"?
- 목표: 구름상자 원리(과포화 증기, 이온화 흔적) / 입자 종류에 따른 흔적 모양(알파: 굵고 짧음, 뮤온: 가늘고 곧음, 전자: 구불구불) / CMS 검출기 층 구조(트래커, ECAL, HCAL, 솔레노이드, 뮤온 챔버)와 각 층에 남는 신호로 입자 식별.
- 실험 A: **확산형 구름상자 만들기** — 투명 플라스틱 통, 검은 바닥판, 이소프로필 알코올(99%), 드라이아이스, 펠트, 손전등. 우주선 뮤온·전자·(가능하면) 알파 흔적 관찰, 흔적 종류별 개수·길이 기록, 1분당 흔적 수 세기. 안전: 드라이아이스 장갑, 환기, 알코올 화기 엄금.
- 실험 B(3D) `sims/t05.html`: **CMS 검출기 탐험** — 실린더형 CMS 단면 층(트래커, ECAL, HCAL, 초전도 솔레노이드, 철 귀환 요크+뮤온 챔버)을 3D로 표시, 층별 보이기/숨기기, 설명 카드. 입자 발사기: 전자, 광자, 뮤온, 양성자/파이온(강입자), 중성미자 선택 → 휘는 트랙(B=3.8T, 하전 입자만), 해당 층에서 에너지 침착(빛나는 블록) 애니메이션. 미션: 각 입자의 "신호 지문" 표 완성, 수수께끼 입자 5개 식별 퀴즈, 중성미자는 왜 안 보이나.
- 업그레이드: 스마트폰 카메라 이미지 센서로 방사선 검출 원리 조사, 거품상자 사진 해석.

### 주제 6. 특수 상대성이론과 우주선 뮤온 (심화과정)
- 핵심 질문: 수명이 2.2 μs뿐인 뮤온이 어떻게 15 km 상공에서 지면까지 도달할까?
- 목표: 로런츠 인자 γ, 시간 지연·길이 수축으로 뮤온 도달 설명 / 지수 붕괴 N = N₀ e^(−t/τ) / E = γmc², 상대론적 운동량 / LHC 양성자의 γ(6.8 TeV → γ ≈ 7250) 계산.
- 실험 A: **우주선 뮤온 계수와 붕괴 통계** — (1) 주제 5의 구름상자로 1분당 흔적 수 측정(재사용), 또는 학교에 있으면 가이거 계수기·CosmicWatch 섬광 검출기로 방향(수직/수평)에 따른 계수율 비교, (2) 주사위(또는 동전) 붕괴 모형: 매 단계 특정 눈이 나오면 "붕괴" → 반감기·지수 붕괴 그래프, 수명 추정. 계산: γ = 1, 10, 30일 때 도달 비율.
- 실험 B(3D) `sims/t06.html`: **뮤온 비행 실험실** — 대기 상층(높이 조절, 기본 15 km)에서 뮤온 다발 생성, 지면 검출기까지 비행. 속력(0.9c~0.9999c) 조절, "고전 물리(시간 지연 없음)"/"상대론" 토글, 지면 도달 수 카운트와 이론값 비교. 뮤온 기준계 보기(대기 두께가 길이 수축됨). 그래프: 고도별 생존 수(고전 vs 상대론). 미션: 고전 계산 시 도달 비율, 상대론 시 도달 비율, γ 측정, 길이 수축 관점으로 같은 답 확인.
- 업그레이드: 1963년 프리시–스미스 실험(워싱턴산–해수면 뮤온 계수) 데이터 재현 계산, CERN 뮤온 저장고리 g−2 실험(1977, γ≈29.3에서 수명 약 64 μs) 이야기.

### 주제 7. 보존 법칙과 불변질량 (심화과정)
- 핵심 질문: 충돌 후 남은 조각들만으로 어떻게 사라진 입자의 질량을 알아낼까?
- 목표: 운동량 보존(2차원 충돌) / 에너지–운동량 관계 E² = (pc)² + (mc²)² / 불변질량 M² = (ΣE)² − |Σp|² (c=1 단위) / 붕괴하는 입자의 질량을 딸 입자 측정값으로 재구성.
- 실험 A: **2차원 충돌과 운동량 보존** — 에어하키 퍽, 동전(컬링), 또는 수레 충돌을 위에서 촬영 → 영상 분석(Tracker 무료 프로그램 또는 프레임 단위 측정)으로 충돌 전후 속도 벡터 측정, x·y 운동량 합 비교. 보충: 폭발형 분리(용수철로 두 수레 밀어내기)로 "정지 입자의 붕괴" 비유 — 두 조각 운동량 크기 같고 방향 반대.
- 실험 B(3D) `sims/t07.html`: **붕괴 재구성 실험실** — 질량 M인 입자가 두 딸 입자로 붕괴(정지 상태/움직이는 상태), 3D로 운동량 화살표, 딸 입자 4-벡터 표 표시. 학생이 측정값(E, px, py, pz)으로 불변질량 계산 → 입력 → 판정. "미지 입자" 모드: 랜덤 질량(J/ψ, Υ, Z, 힉스→γγ 등) 사건 10개를 재구성해 정체 맞히기, 검출기 분해능(가우시안 번짐) 켜기/끄기 → 질량 분포 히스토그램 폭. 미션: 정지 붕괴 시 운동량 합 0 확인, 움직이는 붕괴에서도 불변질량 일정 확인, 미지 입자 3종 판별.
- 업그레이드: 3체 붕괴(중성자 베타 붕괴) 에너지 스펙트럼에서 중성미자 존재 추론(파울리).

### 주제 8. 나만의 LHC 설계하기 (종합과정)
- 핵심 질문: 주어진 예산과 기술로, 목표 에너지에 도달하는 가속기를 어떻게 설계할까?
- 목표: 주제 3(전기장 가속)·4(자기장 휘기)·6(상대론)을 종합해 가속기 변수(둘레, 자기장, 에너지, RF) 사이 관계를 설계에 적용 / 전자 vs 양성자 싱크로트론 복사 손실(∝ γ⁴/r) 비교 / 공학적 절충(비용, 초전도, 터널 길이) 토론.
- 실험 A: **팀 설계 프로젝트 + 모형 가속기** — 모둠별 "가속기 설계 제안서": 목표 에너지(예: 50 TeV 빔), 사용 가능한 자석(일반 2 T / 초전도 8 T / 차세대 16 T), 터널 둘레 선택 → p = 0.3Br로 필요한 반지름·둘레 계산, 비용 추정표(가상 단가), 장단점 발표. 모형: 원형 홈(플라스틱 레일/수영장 누들 반으로 자른 것)에 쇠구슬, 자석·경사로 "킥"으로 가속하는 가우스 가속기(자석+쇠구슬) 시연.
- 실험 B(3D) `sims/t08.html`: **LHC 가상 운전실** — 가속 사슬 3D(Linac4 → PSB → PS → SPS → LHC 링, 크기 비율 표시), 단계별 빔 주입 애니메이션과 각 단계 에너지·γ·속력 표. "설계 모드": 링 반지름·쌍극자 세기·입자 종류(양성자/전자) 슬라이더 → 최대 빔 에너지, 회전당 싱크로트론 복사 손실, 1초당 회전 수(약 11,245회) 계산. 미션: LHC 실제 값 재현(r≈2.8 km, 8.3 T → 약 7 TeV), FCC(둘레 약 91 km, 약 16~20 T) 설계 시 에너지 추정, 같은 링에서 전자를 가속할 때 문제점 발견.
- 업그레이드: 차세대 원형 충돌기(FCC) 논쟁 토론 자료, 충돌 빈도(광도) 개념.

### 주제 9. 사건 분석가 되기: W·Z 보손 찾기 (종합과정)
- 핵심 질문: 수많은 충돌 사건 중에서 W·Z 보손이 만든 사건을 어떻게 골라낼까?
- 목표: 주제 5(검출기 신호)·7(불변질량·운동량 보존)을 종합해 사건을 분류 / 누락 횡운동량(MET)으로 중성미자 존재 추론 / W⁺/W⁻ 비율과 그 의미(양성자 속 u 쿼크가 d보다 많음) / 통계적 불확도(√N).
- 실험 A: **마스터클래스형 사건 카드 분류** — 인쇄한 사건 카드(또는 3D 사건 화면 캡처) 40장을 모둠별로 분류(W→eν, W→μν, Z→ee, Z→μμ, 배경), 집계표, 모둠 결과 합산 → W⁺/W⁻ 비, W/Z 비 계산, 불확도. (국제 마스터클래스 CMS WZ 측정과 같은 구조)
- 실험 B(3D) `sims/t09.html`: **3D 이벤트 디스플레이 분석기** — 원통형 검출기(트래커, 칼로리미터 타워, 뮤온 챔버) 안에 시뮬레이션 사건 표시(트랙 휘어짐 = 전하, 칼로리미터 타워 = 에너지, MET 화살표). 사건 100개(무작위 생성, 실제 비율과 비슷하게: W⁺:W⁻ ≈ 1.4:1, W:Z ≈ 10:1, 배경 포함), 학생이 버튼으로 분류 → 집계표·비율·√N 오차 자동 계산, Z 사건은 두 렙톤 불변질량 히스토그램 자동 누적. 미션: 신호 지문 익히기 5개, 50개 분류, W⁺/W⁻ 비 계산, Z 질량 피크 확인.
- 업그레이드: 실제 CMS W→μν 데이터(`data/cms_wmunu_2011.csv`)로 W⁺/W⁻ 비 계산 → 주제 10과 U1로 연결.

### 주제 10. 실제 CERN 데이터로 발견하기 (종합과정, 마지막 주제)

- 목표: CERN Open Data Portal에서 데이터를 찾고 내려받는 절차를 안다 / 4-벡터로 불변질량을 직접 계산하고 히스토그램을 그린다 / 공명 피크(J/ψ, ψ(2S), Υ, Z)를 찾아 질량을 측정하고 기준값과 비교 / 4렙톤 사건에서 힉스(약 125 GeV)의 흔적 확인 / 신호와 배경, 통계적 유의성 감각.
- 실험 A: **실제 CMS 데이터 분석(스프레드시트 또는 웹 도구)** — `data/` 폴더의 CMS 2011 DoubleMu 데이터(실제), 또는 학생이 직접 opendata.cern.ch record 545에서 내려받은 CSV. 스프레드시트로 M = √((E1+E2)² − (px1+px2)² − (py1+py2)² − (pz1+pz2)²) 계산 → 히스토그램 → 피크 찾기. 결과 보고서(발견 논문 형식: 초록, 방법, 결과, 결론).
- 실험 B(3D) `sims/t10.html`: **CMS 오픈데이터 분석실** — 실제 데이터(`data/js/*.js`)를 불러와 (1) 사건 하나씩 3D로 보기(두 뮤온의 운동량 벡터를 원통 검출기 안 트랙으로; 전하에 따라 휘는 방향), 학생이 4-벡터로 불변질량 직접 계산해 검증, (2) 히스토그램 분석기: 질량 범위·구간 수·로그 스케일 조절, 피크 구간 선택 → 평균·표준편차·사건 수 계산, 가우시안+배경 맞춤(간단한 최소제곱), 기준값 표시 토글, (3) 데이터셋 선택: 이중뮤온 100,000건(질량 스펙트럼 2~110 GeV), Z→μμ 10,583건(pt, η, φ로 질량 계산), 4렙톤 278건(힉스), (4) 내 CSV 불러오기(파일 선택). 미션: J/ψ 질량 측정, Z 질량과 폭 측정, 로그 스케일로 모든 공명 찾기, 4렙톤 125 GeV 근처 사건 수 세기.
